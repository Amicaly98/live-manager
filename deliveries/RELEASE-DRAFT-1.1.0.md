## 2. 本轮验收结论（详见验收报告）

真实 Windows 桌面验收已完成（安装/重装/卸载、窗口与页面、托盘隐藏与恢复、
退出残留、重复打开、导入导出与持久化、分区缓存保护）：

- 通过：**安装到含中文的路径**（布局、内置后端哈希、桌面/开始菜单快捷方式）、
  内置后端免 Python 启动、**在含空格的路径下运行**（整套复制到
  `含 空格 路径\` 后启动全流程正常）、
  页面可达（任务/设置/控制台 + 分区下拉搜索）、托盘隐藏与窗口恢复、
  退出后零残留（`run.exe` / `ffmpeg` / 端口 8000）、重复打开不重复拉起后端、
  Excel 导入（合并）与导出往返、重启后任务保留、分区缓存不被重启/重装覆盖、
  卸载保留用户数据。
- **未验证**：**安装到含空格的路径**（静默安装的自定义路径在首个空格处被
  截断；交互式向导未测）。"含空格路径运行成功" 不等于 "含空格路径安装成功"，
  两者不要混为一谈。
- 发现（**既有行为，本版未修改**）：重复打开时新起的进程会停在一个
  “端口被占用”模态提示上，点掉后才退出。不影响运行中的实例，也不重复
  拉起后端。见 CHANGELOG「已知限制」与验收报告第 5 节。
- 专项复核（2026-09-15 第二轮）：一次全流程自动运行中曾观察到一次额外的
  “全覆盖”导入；在隔离数据目录布置哨兵任务后，用**原脚本选择器**、
  **修正后的对话框内精确定位**、**逐字复用原版脚本完整重放**、
  **“全覆盖→二次确认→取消”** 四条路径复跑，**均未能复现**（每次都只有 1 次
  `mode=merge` 导入；“取消”路径发出 0 次导入请求且任务集合与进度一字节不变）。
